# FoodScan — сканирование штрихкодов и распознавание еды

В этой версии FoodScan добавлены две функции: считывание штрихкодов камерой и распознавание фотографий с помощью TensorFlow Lite.

## 1. Сканирование штрихкодов

На экране **Поиск** доступны два способа ввода:

- **Сканировать камерой** — открывается системный интерфейс Google Code Scanner. После считывания EAN-13, EAN-8, UPC-A, UPC-E, Code 128 или ITF код автоматически передаётся в существующий поиск Open Food Facts.
- **Ручной ввод** — остаётся доступен, если сканер недоступен или код нельзя считать камерой.

Используется `com.google.android.gms:play-services-code-scanner:16.1.0`. Google Code Scanner выполняет обработку на устройстве через Google Play services и не требует от приложения отдельного разрешения `CAMERA`. На устройстве должны быть установлены и актуальны Google Play services. Метаданные в `AndroidManifest.xml` позволяют заранее загрузить UI-модуль сканера при установке приложения через Google Play.

## 2. Распознавание фотографии с TensorFlow Lite

На экране **Распознавание** можно сделать фотографию камерой или выбрать изображение из галереи. Для снимка используется `ActivityResultContracts.TakePicture()` и `FileProvider`, поэтому сохраняется полноразмерный файл, а не маленькая миниатюра. Изображение анализируется на устройстве через TensorFlow Lite Task Vision (`org.tensorflow:tensorflow-lite-task-vision:0.4.4`).

Используемая модель — **Google AIY Food V1**, модель MobileNet V1, обученная для классификации 2023 категорий блюд. Она выдаёт вероятности классов; приложение показывает до пяти наиболее вероятных вариантов и процент уверенности. Модель загружается из TensorFlow Hub при первом запуске функции и сохраняется в `files/foodscan_models/aiy_food_v1.tflite`. После успешной загрузки само распознавание выполняется локально, без обращения к серверу.

Источник модели:

`https://storage.googleapis.com/tfhub-lite-models/google/lite-model/aiy/vision/classifier/food_V1/1.tflite`

## 3. Важные ограничения модели

AIY Food V1 классифицирует визуальные категории блюд, а не конкретные товары из магазина. По фотографии модель не определяет производителя, бренд, точный SKU, ингредиенты, аллергенный состав или пищевую ценность. Модель обучена на наборе пищевых категорий с перекосом в сторону североамериканских блюд и предполагает, что на фотографии хорошо кадрировано именно блюдо. Для определения конкретного упакованного продукта нужно использовать штрихкод и Open Food Facts.

Результат модели является предположением с указанной вероятностью, а не гарантированным распознаванием. Не используйте его как источник сведений об аллергенах или составе.

## 4. Как проверить в Android Studio

1. Откройте папку `FoodScan` в Android Studio и выполните **Sync Project with Gradle Files**.
2. Подключите физический Android-смартфон с Google Play services. Для Code Scanner предпочтительнее реальное устройство, а не эмулятор без Google Play.
3. Запустите приложение, авторизуйтесь или выберите гостевой режим.
4. Откройте **Поиск** → **Сканировать камерой**, наведите камеру на EAN-код продукта. После считывания приложение должно заполнить поле и выполнить поиск в Open Food Facts.
5. Откройте **Распознавание** → **Сделать фото** или **Выбрать из галереи** → **Распознать продукт**. При первом запуске потребуется доступ в интернет для загрузки файла модели. Дождитесь окончания загрузки и проверьте список предсказаний.
6. Повторите распознавание после отключения интернета: если модель уже сохранена локально, инференс должен работать без сети.

## 5. Изменённые основные файлы

- `app/build.gradle.kts` — зависимости Google Code Scanner и TensorFlow Lite Task Vision, настройка `noCompress` для `.tflite`.
- `app/src/main/AndroidManifest.xml` — метаданные Google Code Scanner и `FileProvider` для фотоснимков.
- `app/src/main/res/xml/file_paths.xml` — путь к файлам камеры в кэше приложения.
- `app/src/main/res/layout/fragment_scan.xml` — кнопка сканирования камерой и поле ручного ввода.
- `app/src/main/res/layout/fragment_recognition.xml` — экран захвата/выбора фотографии и результата классификации.
- `ScanFragment.java` — вызов Google Code Scanner и автоматическая передача штрихкода в `MainViewModel`.
- `RecognitionFragment.java` — создание фото, выбор изображения и отображение top-5 предсказаний.
- `MainViewModel.java` — асинхронный запуск распознавания и состояние загрузки/ошибок.
- `RecognitionRepositoryImpl.java` — загрузка, кэширование и запуск AIY Food V1 через TensorFlow Lite.
- `RecognitionResult.java`, `RecognitionPrediction.java` — модель результатов классификации.

## 6. Проверка сборки

XML-разметки и `AndroidManifest.xml` можно проверить через Android Studio или `./gradlew :app:assembleDebug`.
